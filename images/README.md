# Photos

Drop image files straight into this folder.

**Originals, please.** Full size, straight off the camera or from the
photographer. The site shrinks them to fit — it can't grow them back.
The downscaled copies from the old Wix site aren't good enough.

Name them so you can tell what they are later, in lower case with hyphens
instead of spaces:

    and-it-rains-salford-arts-01.jpg
    joanna-portrait.jpg

Then tell Claude which photo goes where, or add it to a page yourself:

    <img src="images/and-it-rains-salford-arts-01.jpg" alt="Two actors mid-scene, lit in red">

The `alt` text describes the picture for anyone who can't see it. Write what's
actually happening in the shot.
